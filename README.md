# Hi-Tech Map

## Purpose

Hi-Tech Map is a structured knowledge base for CS students covering core topics from algorithmics and machine learning to networks, systems, and security. It provides a navigable map of concepts with consistent structure—scaffolded for future content and designed to be turned into a static website.

## How to Navigate

- **SUMMARY.md** — Table of contents with links to all pages in order.
- **00-big-picture/** — Overview: AI/ML/DL, roles, production.
- **01-algorithmics/** — Foundations: algorithmics, complexity, data structures, parallel vs serial, algorithms in ML.
- **02-ml-core/** — ML concepts: vectors, classification, loss, neural networks, transformers, diffusion.
- **03-networks/** — Networking: client-server, OSI, TCP/IP, HTTP, DNS, ports, backend relevance.
- **04-systems/** — Systems: computer vs server, hardware basics, CPU vs GPU, accelerators (FPGA, TPU), Docker, Kubernetes, OpenShift, CI/CD.
- **05-security/** — Security: credentials, sandbox, red/blue/purple, MITRE ATT&CK, security & ML.
- **06-data/** — Data: what is a database, relational vs NoSQL, schemas and models, queries and indexes, db and ML.

## Suggested Learning Path

- Start with **00-big-picture** for context.
- Build foundations with **01-algorithmics**.
- Follow **02-ml-core** for ML concepts.
- Study **03-networks** for how systems communicate.
- Explore **04-systems** for deployment and infrastructure.
- Finish with **05-security** for secure design and operations.
- Study **06-data** for databases and their relation to ML.

## Conventions

- Each page has: H1 title, Why it matters, Core ideas, Common confusions, Tiny example, Links to other notes.
- Links use relative paths (e.g., `../02-ml-core/vectors-and-spaces.md`).
- Filenames: lowercase, hyphen-separated.
- Folders: numbered for ordering (00, 01, …).
